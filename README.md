# 🍎 AI Food Calorie Calculator

An AI-powered application that analyzes food images and estimates their calorie content using Google Gemini AI and Streamlit.

## Features

- Upload a food image
- Identify the food using AI
- Estimate calories
- Display nutritional information
- Simple Streamlit interface

## Technologies

- Python
- Streamlit
- Google Gemini AI
- Pillow
- python-dotenv
